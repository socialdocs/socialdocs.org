# Welcome to SocialDocs

We're excited to launch **SocialDocs** — the comprehensive developer resource for ActivityPub, Mastodon, and the Fediverse.

<!-- truncate -->

## Our Mission

Building for the Fediverse should be accessible to every developer. Whether you're creating a new social platform, adding federation to an existing app, or just curious about how it all works, SocialDocs aims to be your go-to resource.

## What You'll Find Here

- **Getting Started Guides**: From "What is the Fediverse?" to building your first ActivityPub server
- **Protocol Specifications**: Deep dives into ActivityPub, ActivityStreams, WebFinger, and HTTP Signatures
- **Implementation Guides**: Step-by-step tutorials for common tasks
- **API Reference**: Complete documentation for object types, activities, and endpoints
- **Ecosystem Directory**: Overview of server software, libraries, and tools
- **Developer Tools**: Validators, inspectors, and testing resources
